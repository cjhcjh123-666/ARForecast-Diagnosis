## 1. 命题与贡献

**"Recognize, Don't Generate"**：语言预训练对时序预测的价值是**可复用的时序结构先验**（擅长"识别"），而非数值生成能力（"生成"脆弱）。
受控实验表明：预训练大幅提升识别（含 OOD 组合迁移）；冻结模型的数值生成在**所有模型家族（GPT-2/Qwen3）× 规模（82M-8B）× 难度 × prompt/解码**下都保持 5-15× 误差。
对争议的答复：Tan 2024 与新工作的矛盾源于混淆"识别/生成"；"要不要 LLM"——同数据监督分类器（PatchTST/MLP）域内 99% 但 OOD 13-34%、专业时序基础模型（Chronos×6）域内 100% 但 OOD 9-36%，**只有冻结预训练 LLM 8B 达 67.8%**。

## 3. 可控协议
- 动力学：trend / periodic(P∈{12,24}) / local(AR1 φ∈[0.7,0.95]) / mixture(趋势+正弦) / regime(前60%趋势后转正弦)；前3类干净、后2类 OOD。
- 窗口：C=64, H=16；每窗口独立生成（total=80）；context-only 标准化。
- 文本：`History: +0.12 -0.04 ... Forecast:`，clamp [-9.99,9.99]，两位小数。
- probe：冻结 last-token hidden → 线性 softmax（手写全批量 GD，lr=0.5, l2=1e-3, 2000 步）。
- 专家：trend(OLS polyfit deg1) / periodic(自相关周期+季节naive+阻尼AR1) / local(AR5+稳定性阻尼)。
- 模型：Qwen3-0.6B/1.7B、**Qwen3-8B（= Qwen/Qwen3-8B-Base 语言主干，Wave-MoE Qwen3TS checkpoint，TS 模块未用）**、GPT-2、DistilGPT2。

## 7. 复现细节（Appendix B，全部来自代码，无 TODO 遗留）

1. **synthetic**：a∈[0.03,0.18](trend)/[0.01,0.06](mixture)/0.08(regime)；**无独立截距 b**（公式删 b）；A∈[0.5,1.5](per)/[0.4,1.2](mix)/1.0(regime)；P∈{12,24}；φ∈[0.7,0.95]；ε~N(0,0.05)（local 用 σ=0.15）；**phase ψ~Uniform[0,2π)（dynamics.py L55，每窗口独立采样）**；AR x₀=ε₀；每窗口独立生成 total=80；150/类，train90+test60；无重叠无stride；seeds 7/17/27（0.6B 加37/47）。
2. **probe**：全批量 GD，lr=0.5，l2=1e-3，2000 步，输入 (X-mean)/std；**输入 dim = 模型 hidden：0.6B=1024, 1.7B=2048, 8B=4096, GPT-2=768, DistilGPT2=768**（模型内 pre/random 同 dim）。
3. **hidden 提取**：`out.hidden_states[-1][row_idx, lengths]`，lengths=attention_mask.sum-1（**最后一个非 padding token**，非 [:, -1, :]）。
4. **layerwise**：每层**独立重训** probe（`for layer: softmax_regression(tr_h[layer],...)`）。
5. **CKA**：**normalized linear CKA**（中心化 Gram，Frobenius 归一化，HSIC/‖·‖‖·‖）。
6. **专家**：trend=OLS polyfit(deg1)（**非 robust**，如需保留"robust"可换 Theil-Sen）；periodic=自相关 lag∈[3,32) 阈值0.4 + 季节naive + 阻尼AR1(φ∈[0,0.95])；local=AR5 lstsq + 稳定性阻尼(系数×0.9,≤60次)。
7. **adaptation**：token-level CE + prompt 掩码，LoRA r8/α16/dropout0.05/qkv+o，AdamW+grad clip1.0，lr LoRA=2e-4/full=1e-4，batch4，epochs5，train256/val64/test64，ETTm1-OT，bf16；无独立 readout。
8. **baselines 同窗口同 split**：MLP/PatchTST/Chronos 与 Qwen 用**完全相同** synthetic 窗口与 90/60 split（seed 默认7；Qwen 报 3 seeds 均值，baseline 为 seed7 单值——附录注明）。
9. **generation**：base prompt 同 family-scale；instruction/few-shot 字符串见 `iclr_gen_robustness.py`；max_new_tokens 160(family)/200(robust)/120(constrained)；greedy/temp0.7/temp1.0(top_p=1.0)；parser=`re.findall(r"[+-]?\d\.\d\d",text)` 取前H（**全仓 6 处均为转义 `\.`，无 regex bug，已验证只匹配字面小数点**）；constrained=按 `[空格][符号][数字][.][数字][数字]` 逐位 mask。
10. **real data**：ETT/Exchange/Illness 用 OT、Electricity/Traffic 用 channel0、Weather 用 T(degC)——**单变量通道，非 multivariate**（正文改"univariate channels from 15 real datasets"）；ETT 12/4/4、其余 70/30；M4 从 train 序列内采样；每数据集 ≤300 窗口。
11. **模型定名**：8B = **Qwen/Qwen3-8B-Base**（Wave-MoE Qwen3TS checkpoint 的语言主干，TS 模块随机初始化未用）——正文写 "Qwen3-8B" + 脚注披露。
12. **router 样本**：训练 270/seed（3类×90），OOD 测试 120/seed（mixture60+regime60），8B 合并360、0.6B 合并600。
13. **bootstrap**：window-level、跨 seed 合并、percentile、生成 ratio-of-sums。
