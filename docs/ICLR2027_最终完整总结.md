## 1. 一句话命题与核心贡献

**"Recognize, Don't Generate"（识别，不要生成）**：
把 LLM 做时序预测拆成两种能力——**识别**时序结构（trend/periodic/local/mixture/regime）与**生成**未来数值。
受控实验表明：语言预训练大幅提升**识别**（含 OOD 迁移），但对冻结模型的**数值生成**没有帮助（5-15× 误差、parse 不稳定），
且该不对称性在模型家族（GPT-2/Qwen3）× 规模（82M-8B）× 难度（context/noise/horizon）× prompt/解码（greedy/采样/few-shot/指令）下全部成立。

**对审稿争议的答复**：
- Tan 2024（说没用）vs 2025-2026 新工作（说有用）的矛盾 → 两边都部分正确，因为把"识别"和"生成"混为一谈。
- "要不要 LLM？" → 同数据训练的 PatchTST/MLP 域内 99% 但 OOD 路由仅 13-34%；**专业时序基础模型 Chronos 域内 100% 但 OOD 路由仅 9-36%**；
  只有冻结预训练 LLM（8B）OOD 路由达到 67.8%。**迁移来自语言预训练表示，与模型容量/时序预训练规模无关。**

## 3. 可控实验协议（全部实验共用）

- **动力学**：trend（线性+噪声）、periodic（周期 12/24 正弦）、local（稳定 AR(1), φ∈[0.7,0.95]）、mixture（趋势+正弦）、regime（前 60% 趋势后转正弦）。
  前 3 类为"干净"，后 2 类保留为 **OOD 测试**。
- **窗口**：context=64，horizon=16（除多 horizon 实验用 24/48）。按 context 标准化。
- **文本协议**：`History: +0.12 -0.04 ... Forecast:`，数值 clamp [-9.99,9.99]、两位小数。
- **Probe**：冻结模型 last-token hidden → 线性 softmax probe（numpy 梯度下降 2000 步）。
- **特征 floor**：9 个手算统计量（斜率、线性 R²、波动率、lag-1 自相关、主周期/强度、谱熵、谱峰集中度、极差比）。
- **专家**：trend=稳健线性外推、periodic=自相关周期检测+季节 naive、local=阻尼 AR(5)。oracle=各窗口实际误差最小的专家。
- **模型**：Qwen3-0.6B/1.7B（vanilla）、Wave-MoE Qwen3-8B（语言主干）、GPT-2 124M、DistilGPT2 82M。随机对照=同架构重初始化。
- **Router**：probe 训练于 3 干净类 → 零样本路由到未见 mixture/regime（E4）；或路由到真实数据窗口（R6）。

## 5. 各实验详细结果

### E1 受控预报消融（LoRA，3 seeds: 7/17/27）

| 数据集 | 预训练 MSE | 随机 MSE | 相对降幅 |
|---|---|---|---|
| synthetic_sine | 0.0094 ± 0.0006 | 0.0212 ± 0.0011 | 2.2× |
| ETTm1 | 0.0099 ± 0.0017 | 0.2453 ± 0.1366 | 25× |
| ETTh1 | 0.0487 ± 0.0097 | 0.2896 ± 0.2059 | 6× |

小模型 2×2（0.6B/1.7B × LoRA/full-FT，`results/icassp/small_e1/`）：
随机 + 全量微调仍差 10-13× → **排除"随机 8B + rank-8 LoRA 学不动"的公平性质疑**。
预训练 parse 率全 1.0、方差小；随机方差大、偶有 parse 失败。

### E2 冻结结构识别（5 类，3 seeds）

| 模型 | 预训练 | 随机 | 特征 floor |
|---|---|---|---|
| DistilGPT2 | 0.973±0.009 | 0.744±0.022 | 0.990 |
| GPT-2 | 0.980±0.008 | 0.699±0.041 | 0.990 |
| Qwen3-0.6B | 0.984±0.006 | 0.789±0.010 | 0.993 |
| Qwen3-1.7B | 0.979±0.011 | 0.837±0.012 | 0.990 |
| Qwen3-8B | 0.963±0.005 | 0.906±0.009 | 0.990 |

→ 识别全稳；预训练优势 GPT-2 家族最大（~28% gap）；干净合成数据大家都高（特征 floor ~99%），
**预训练优势体现在 OOD 迁移（E4）而非域内分类**。

### R2b 逐层 probe（Qwen3-0.6B，29 层含 embedding）

- 预训练：层 0（embedding）0.20（chance）→ 层 1 起 ~0.93 → 上层平台 **0.98**
- 随机：层 2-3 峰值 ~0.90 → 深层**衰减到 0.79**
- 结论：语言预训练让时序结构信息**分布全栈**；随机网络只有浅层有、随深度丢失。
  数据：`results/iclr/layerwise/qwen3_0.6b{,_random}/summary.json`

| 识别准确率 | 0.967 | **0.983**（local 0.95→0.98, mixture 0.92→0.98） |
| 表示 CKA | — | 0.453 |
| probe 方向 cos | — | 0.075 |
| mean abs delta | — | 0.692 |

→ 预测微调**不侵蚀识别表示，反而轻微锐化**，但表示几何被大幅重写。

### E3 识别 vs 生成（同窗口，3 seeds）

| 模型 | 识别 | 生成 parse | 生成 MSE | oracle MSE | 比值 |
|---|---|---|---|---|---|
| Qwen3-0.6B | 0.98 | 0.980 | 3.31 | 0.34 | 9.9× |
| Qwen3-1.7B | 1.00 | 0.592 | 2.73 | 0.34 | 8.2× |

→ **识别鲁棒、生成脆弱**。GPT-2 parse 100% 但误差比最大（12-15×）→ 生成失败不是格式问题。

### E3b 语法约束解码（Qwen3-0.6B/8B）

| 解码 | parse | MSE/oracle |
|---|---|---|
| 自由贪心 | 0.267 | 5.5× |
| 语法约束 | 1.000 | 6.2× |

→ 强制合法数值 token 后 parse=100%，误差比仍 6.2× → **排除格式/序列化失败**。

### E3c 生成鲁棒性（P0.2，同窗口全变体）

| 变体 | Qwen3-0.6B parse/ratio | Qwen3-8B parse/ratio |
|---|---|---|
| greedy | 1.000 / 9.6× | 0.275 / 5.9× |
| temp 0.7 | 0.950 / 7.1× | 0.375 / 8.0× |
| temp 1.0 | 0.925 / 8.4× | 0.300 / 9.7× |
| 显式指令 | 0.925 / 8.8× | 0.475 / 8.5× |
| few-shot 1 | 1.000 / 8.3× | 0.925 / 4.9× |
| few-shot 2 | 1.000 / 9.9× | 0.875 / 7.4× |

⚠️ 初版 gen_robustness 用了错误的窗口切片（`contexts[90:]` 而非按类 test 切片），窗口集中在 periodic train、oracle=0.576；
已修复（`test_idx[gen_idx]` 正确分层），修正后 oracle=0.336 与 family-scale 对齐，greedy 8B = 5.9× 与 E3 一致。

→ **所有 prompt/解码变体下误差比保持 4.9-9.9×**；采样不救（降 parse 且 ratio 仍高）、few-shot 提 parse 但 ratio 仍 ≥4.9×、指令伤覆盖率。
"don't generate" 与格式/解码/prompt 无关，是**数值续写能力缺陷**。

## 14. Window-level bootstrap（P0-5a 升级，新增）

把 bootstrap 从 seed-level 升级为 **window-level**（resampling unit = 单条 test window，跨 seed 合并后 2000 次有放回重采样；生成比值用 ratio-of-sums 与正文点估计一致）：

**Qwen3-8B**（3 seeds 合并，路由 n=360）：
| 量 | 点估计 | 95% CI |
|---|---|---|
| 路由 pre acc | 0.681 | [0.633, 0.728] |
| 路由 random acc | 0.286 | [0.239, 0.336] |
| 路由 feature acc | 0.133 | [0.100, 0.172] |
| 识别 pre | 0.963 | [0.951, 0.974] |
| 识别 random | 0.906 | [0.886, 0.923] |
| 路由 MSE pre/rnd/feat | 0.745/1.053/1.222 | [0.68,0.82]/[0.98,1.13]/[1.15,1.29] |
| 生成/oracle 比 | 5.28× | [3.22, 9.83]（n=32 解析窗口） |

**Qwen3-0.6B**（5 seeds 合并，路由 n=600）：
| 路由 pre/rnd/feat | 0.337/0.217/0.162 | [0.30,0.38]/[0.18,0.25]/[0.13,0.19] |
| 识别 pre/rnd | 0.984/0.789 | [0.977,0.989]/[0.769,0.809] |
| 生成/oracle 比 | 9.64× | [7.52, 12.33]（n=196） |

→ 8B 路由三方法 CI 完全不重叠；比 seed-level 更紧、更专业。已写入论文 A.9（Statistical details）。
数据：`results/iclr/bootstrap_window/{qwen3_8b,qwen3_0.6b}_full.json`
脚本：`scripts/iclr_bootstrap_window.py` + `scripts/iclr_gen_save_windows.py`
