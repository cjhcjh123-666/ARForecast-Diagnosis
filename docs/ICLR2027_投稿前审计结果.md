## 1. Qwen3-8B 权重身份（最高优先）—— ⚠️ 发现不一致，已用官方模型重跑

**结论：Wave-MoE Qwen3TS-8B 的语言主干 ≠ 官方 Qwen/Qwen3-8B-Base**
- 399 个共享 tensor 中 **397 个有差异**，max abs diff = **0.0405**（lm_head.weight）
- 差异分布：299 个 tensor max diff ∈ [1e-2, 0.1]；98 个 ∈ [1e-3, 1e-2]；仅 2 个完全相同
- 记录：`results/iclr/identity_check/summary.json`；官方权重已下载至 `models/qwen3-8b-base/`（5 shard + tokenizer）

**已按官方 Qwen3-8B-Base 重跑全部 8B 核心实验**（`results/iclr/probe_official/`、`multi_dataset_router/qwen3_8b_official/`）：

| 指标 | Wave-MoE 8B（旧） | **官方 8B-Base（新）** |
|---|---|---|
| 识别（window CI） | 0.963 [0.951,0.974] | **0.981 [0.971,0.990]** |
| 生成 parse | 0.267 | **1.000** |
| 生成/oracle | 5.5× | **3.9-4.9×**（3 seeds） |

→ 官方模型结果**更强更干净**（识别 98%、parse 100%、路由 86%）。论文 8B 全部数字必须替换为官方版。
→ 之前"parse 随规模降到 27%"的故事是 Wave-MoE checkpoint 假象；官方 8B parse=100%，改为"官方 8B 也能 parse 100% 但误差仍 4-5×"。

## 2. 时间顺序控制（Qwen3-8B-Base，seed7）—— ✅ 完成

| 条件 | 识别 | OOD 路由 |
|---|---|---|
| LLM 原始顺序 | 0.967 | 0.642 |
| LLM shuffled（打乱时序） | **0.607**（↓） | 0.350（↓） |
| LLM 随机初始化（原始） | 0.910 | 0.258 |
| 特征（时序统计量，原始） | 0.980 | 0.125 |
| 特征（shuffled） | 0.427（↓） | 0.192 |
| **marginal-only（无时序，仅分位数/偏度/峰度）** | 0.917 | **0.842** |

**结论**：
- LLM 识别在打乱时序后从 0.967 降到 0.607 → **模型确实使用时间顺序**（可写 "temporal structure"）
- ⚠️ **重要警示**：marginal-only（无任何时序）OOD 路由达 0.842 > LLM 0.642，因为 **mixture/regime 的 oracle 87% 是 trend**（104/120），"恒选 trend"=87% 命中。**E4 合成路由准确率被 trend 主导，LLM 路由（官方 86.4%）≈ 恒选 trend（87%）**。
- **论文必须重写 E4 定位**：合成 OOD 路由准确率不能作为"LLM 最优路由"证据；应强调 (a) 识别迁移（分类泛化、依赖时序）、(b) 真实数据路由（R6，oracle 非 trend 主导）。

## 3. 非 oracle 生成参照（第 3 项）—— ✅ 完成

官方 8B（3 seeds，parse 100%，n=120 解析窗口）LM MSE 相对各 baseline：

| baseline | 8B LM/baseline（每 seed） | 0.6B LM/baseline |
|---|---|---|
| Persistence（末值重复） | 1.00-1.39× | 1.71-3.26× |
| Best fixed expert（target-aware） | 1.82-2.08× | 3.68-4.94× |
| Context-only router（特征路由，可部署） | 1.67-2.08× | 4.13-5.89× |
| Oracle（下界诊断） | 3.89-4.91× | 7.13-12.25× |

→ 冻结 LLM 生成**不仅比看到未来的 oracle 差，还比纯 context-only 基线（persistence/特征路由）差**。"don't generate" 更强。数据：`results/iclr/gen_baselines/*`。

## 6. Full fine-tuning 3 seeds（第 6 项）—— ✅ 完成（Qwen3-0.6B, ETTm1）

| 初始化 | full-FT MSE（seeds 7/17/27） | mean±std |
|---|---|---|
| pretrained | 0.0118 / 0.0136 / 0.0089 | 0.0114±0.0019 |
| random | 0.2802 / **0.0229** / 0.4140 | 0.2390±0.1623 |

→ 平均比值 **20.9×**，但 **random 方差极大**（seed17 random 0.0229 ≈ pretrained！）。
**诚实表述**：random full-FT 通常差 ~20×，但跨 seed 方差大、偶尔能收敛到接近 pretrained。
**论文不能写"10-13×"或"full-FT 无关"**；应写 "random full-FT 平均显著更差但高方差"。
