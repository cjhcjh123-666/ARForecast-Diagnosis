## 1. 一句话命题

**"Recognize, Don't Generate"（识别，不要生成）**：
语言预训练对时序预测的真正价值，是给 LLM 一个**可复用的时序结构先验**
（擅长"识别"动力学），而不是数值生成能力（"生成"很脆弱）。
这与 Tan 2024（说没用）和 2025-2026 新工作（说有用）的争论直接对话：
两边都部分正确，因为大家把"识别"和"生成"两种能力混为一谈。

## 2. 为什么投 ICLR（分析类）

老板定调：不要求方法创新，做完整、诚实、有深度的分析论文。
对比 ICASSP 版，ICLR 版补齐了：
- **模型规模**：0.6B / 1.7B / 8B 三档
- **统计严谨性**：3-5 seeds + bootstrap CI
- **非 LLM 对照**：PatchTST / MLP 学习式路由 baseline
- **表示机制**：逐层 probe + 微调前后对比
- **难度扫描**：context / noise / horizon
- **数据广度**：15 个真实数据集（ETT×4、电、天气、汇率、流量、流感、M4×6）

## 3. 核心实验与结论

### R1 受控消融（E1）—— 语言预训练确实有用
只换初始化，其余全同（架构/tokenizer/窗口/LoRA）：
| 数据 | 预训练 MSE | 随机 MSE | 降幅 |
|---|---|---|---|
| synthetic_sine | 0.0094 | 0.0212 | 2.2× |
| ETTm1 | 0.0099 | 0.2453 | 25× |
| ETTh1 | 0.0487 | 0.2896 | 6× |
小模型 2×2（0.6B/1.7B × LoRA/全量微调）：随机+全量微调仍差 10-13×，排除 LoRA 伪影。

### R2 冻结识别（E2）+ 逐层分析
- 5 类动力学识别：预训练 96-98% vs 随机 79-91%（0.6B/1.7B/8B）
- **逐层**：预训练模型结构信息分布于全栈（层 1 起 93%→上层 98% 平台）；
  随机模型仅在浅层有（层 2-3 峰值 90%→深层衰减到 79%）

### R3 识别 vs 生成（E3）—— 核心对比
同一批窗口：
| 模型 | 识别 | 生成 parse | 生成 MSE/oracle |
|---|---|---|---|
| 0.6B | 98% | 98% | 9.8× |
| 1.7B | 98% | 57% | 8.1× |
| 8B | 96% | 27% | 5.5× |
- 语法约束解码 → parse 100%，但误差仍 6.2× oracle（排除格式问题）

### R4 零样本路由（E4）+ 非 LLM 对照
训练 3 干净类 → 测试未见 mixture/regime：
| 路由 | OOD 命中率 | MSE |
|---|---|---|
| Oracle（上界） | — | 0.452 |
| Hand features | 0.128 | 1.278 |
| 随机 Qwen | 0.289 | 1.079 |
| PatchTST（域内 99%） | 0.133-0.217 | 1.36-1.76 |
| MLP（域内 ~99%） | 0.275-0.342 | 0.83-1.17 |
| **冻结预训练 Qwen（8B）** | **0.678** | **0.739** |
→ 同样数据训练的监督分类器 OOD 全崩；迁移来自语言预训练表示。

### R5 规模（0.6B/1.7B/8B）
识别全稳（96-98%）；生成 parse 随规模下降（98%→57%→27%）且误差 5-10×；
路由优势在 8B 最大（0.678 vs 随机 0.289 vs 特征 0.128，CI 不重叠）。

### R6 真实数据路由（15 数据集）
8B：LLM 路由在 ETT×3、汇率（59×）、天气、流感上大幅优于特征路由；
同质周期数据上追平"恒选 periodic"；电/流量上特征路由仍优；M4 上两者都失败。
→ 诚实的边界：识别迁移需要多样性结构，不普适。

### R7 难度扫描（P1-1a）
- context：识别 0.94→0.98 稳定；生成比 5.8×→8.6×
- noise：识别 0.98→0.91 仅轻微下降；生成保持 7-8×
- horizon：识别 0.967→0.992 上升；生成比 6.5×→8.4× 上升（支持 ρ^H 形式化）

### R8 微调前后表示（P0-2a）
8B + ETTm1 LoRA adapter：识别 0.967→0.983（不降反升，local/mixture 提升最大）；
表示重排明显（CKA 0.45、probe 方向 cos 0.08）。
